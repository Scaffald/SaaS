# Rich Text Editor Implementation

## Overview

Implemented a cross-platform rich text editor solution for profile descriptions, experience details, and other formatted text fields using TipTap (web) with plans for TenTap (React Native).

## What Was Built

### 1. Rich Text Editor Component (`packages/ui/src/components/rich-text/`)

#### Core Files
- **RichTextEditor.web.tsx** - Web implementation using TipTap
- **types.ts** - TypeScript interfaces and types
- **utils/constants.ts** - Configuration constants and limits
- **utils/sanitize.ts** - Sanitization and validation utilities
- **index.ts** - Public API exports
- **README.md** - Comprehensive documentation

#### Features
- Bold, Italic, Underline formatting
- Bullet and numbered lists
- Character count with limits
- Auto-sanitization of content
- Plain text extraction
- Real-time validation
- Error display
- Disabled/read-only states

### 2. Database Migration (`packages/supabase/migrations/20241103_add_rich_text_fields.sql`)

#### Tables Updated
1. **private.profile** - `about_rich`, `about_plain`
2. **private.user_experience** - `description_rich`, `description_plain`
3. **private.user_education** - `description_rich`, `description_plain`
4. **public.jobs** - `description_rich`, `description_plain`
5. **public.organizations** - `description_rich`, `description_plain`

#### Features
- TipTap JSON storage with JSONB columns
- Automatic plain text extraction via triggers
- Full-text search indexes
- 5000 character limit constraints
- Automatic migration of existing plain text data

### 3. Utilities and Helpers

#### Sanitization Functions
- `sanitizeTipTapJSON()` - Remove unwanted marks/nodes
- `extractPlainText()` - Extract plain text for counting
- `createEmptyDocument()` - Create empty editor state
- `isContentEmpty()` - Check if content is empty
- `plainTextToTipTap()` - Convert plain text to TipTap JSON
- `validateCharacterLimit()` - Validate content length

#### Constants
- Field-specific character limits (500-3000 chars)
- Placeholder text for each field type
- Allowed marks: bold, italic, underline
- Allowed nodes: doc, paragraph, text, lists

## Configuration

### Character Limits
- **Profile About**: 500 characters
- **Experience Description**: 1000 characters
- **Education Description**: 500 characters
- **Job Description**: 3000 characters
- **Organization Description**: 1000 characters
- **Database Maximum**: 5000 characters (enforced)

### Security
- Only allowed marks: bold, italic, underline
- Only allowed nodes: paragraphs, lists, text
- No links, headers, custom HTML, or images
- Client-side and server-side sanitization

## Usage Example

```tsx
import { RichTextEditor } from '@app/ui/components/rich-text'
import type { JSONContent } from '@tiptap/core'
import { useState } from 'react'

function ProfileForm() {
  const [about, setAbout] = useState<JSONContent | null>(null)

  return (
    <RichTextEditor
      value={about}
      onChange={setAbout}
      fieldType="PROFILE_ABOUT"
      showCharacterCount
    />
  )
}
```

## Technical Details

### Storage Format
Content is stored as TipTap JSON:

```json
{
  "type": "doc",
  "content": [
    {
      "type": "paragraph",
      "content": [
        {
          "type": "text",
          "text": "Sample text",
          "marks": [{ "type": "bold" }]
        }
      ]
    }
  ]
}
```

### Plain Text Generation
The database automatically generates plain text via triggers for:
- Full-text search indexing
- Character counting
- Preview generation
- Backwards compatibility

### Performance Considerations
- Plain text is indexed for fast search
- TipTap JSON is stored as JSONB for efficient queries
- Triggers run on INSERT/UPDATE only
- Character limits prevent excessive content
