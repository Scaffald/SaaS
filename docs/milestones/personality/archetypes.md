## Overview

This document defines the 8 proprietary Scaffald Archetypes with rich lore, core traits, psychometric mappings, and visual identity elements.

## Required Content

For each archetype, we need:

- **Archetype Name:** Distinct, memorable name
- **Psychological Lore:** Short story or mythos (200-300 words) that users emotionally connect with
- **Core Traits:** 3-5 defining characteristics
- **Mapping to Open-Source Dimensions:**
  - IPIP/Big Five alignment (e.g., high Openness, low Neuroticism)
  - HEXACO profile (if applicable)
  - RIASEC interest pattern
  - VIA Strengths correlation
- **Visual Identity Elements:**
  - Primary narrative/lore (required)
  - Suggested color palette (optional)
  - Symbol/icon concepts (optional)
  - Environment/setting descriptions (optional)
