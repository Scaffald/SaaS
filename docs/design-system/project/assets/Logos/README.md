# Logos

- `scaffald-mark.svg` — the scaffold-frame mark: a cyan-to-teal gradient (`#76eaff` → `#239cb2`) frame on two `#2a7f8e` feet. Multi-ink; use as-is, never recolour. Minimum 24px.
- `scaffald-wordmark.svg` — the mark with the Scaffald wordmark set in `#2a7f8e` (4.6:1 on white, 4.0:1 on gray-900). For headers and documents at 120px wide or more.
- `scaffald-wordmark.png` — raster wordmark, 1827 × 297, for surfaces that cannot take SVG.
- `scaffald-app-icon.png` — the 1024 × 1024 app icon as shipped to the stores.

The mark's teal and gradient are brand marks, not interface tokens: the UI accent is `primary-600`.
