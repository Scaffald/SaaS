## Execution plan

### Phase A — Backlog hygiene (~30 min)

1. Verify the 7 v1.1.0 In TestFlight issues actually shipped → bulk close.
2. Triage v1.3.0 stragglers: keep on v1.5.0 train or relabel v1.6.0.
3. Confirm @dusan Figma status for SC-33/34/36 so the audit has a target.

### Phase B — Playwright iOS-viewport sweep (~1–2h)

`scripts/audit/ui-sweep.mjs`:

- Auth: programmatic login as `clay@unicorn.love` against `.env.dev` Supabase
  (3 projects seeded). Persist storageState so each test reuses the session.
- Iterate the route list extracted from `apps/scaffald/app/**/*.tsx`. Skip
  `_layout.tsx` and pure component files.
- Viewport: **390×844** (iPhone 14). Plus a second pass at **768×1024**
  (iPad) to catch responsive breaks.
- Output: `docs/agents/audits/2026-05-26-ui-audit/{group}/{route}.png`
- Manifest: `docs/agents/audits/2026-05-26-ui-audit/manifest.json` with
  `{ route, screenshot, viewport, capturedAt }`.

Existing scaffolding to reuse:
- `apps/scaffald/tests/e2e/playwright.config.ts` (baseURL = localhost:8081,
  starts `expo start:web` automatically).
- `apps/scaffald/tests/e2e/auth.spec.ts` (helper stubs — needs filling in).

### Phase C — Visual review + iOS sim verification (~1–2h)

1. Walk every screenshot, flag findings per page into
   `docs/agents/audits/2026-05-26-ui-audit/findings.md`.
2. Severity buckets: **blocker** (broken/unusable), **polish** (works but ugly),
   **nit** (cosmetic).
3. Pick top ~10 → `pnpm ios:run`, capture native screenshots with
   `xcrun simctl io booted screenshot` to verify safe-area / status-bar /
   modal sheet / keyboard behavior. Web pass can't catch these.

### Phase D — File findings + cut v1.6.0 scope (~1h)

1. Bulk-file findings as Tasks in **Unicorn org → Dogfood Bugs (Open)**
   punchlist (in-product, at `/employers/org/unicorn/tasks`). Use
   `scripts/migrate-dogfood-md-to-tasks.ts` as template.
2. From the filed Tasks, promote the v1.6.0 cut into Linear with `v1.6.0`
   label in **Todo** state. Linked back to Task IDs in the description.
3. Close SC-18, SC-19, SC-20, SC-21, SC-22 with a link to the audit doc.
4. v1.6.0 release: standard flow per
   [`RELEASE-PROCESS.md`](../RELEASE-PROCESS.md). Schedule after v1.5.0
   ships to TestFlight.
